# cafe-landing

가상의 카페 "모닝글로우"를 소개하는 간단한 랜딩 페이지입니다. 별도 빌드 없이 HTML과 CSS만으로 만들었습니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 본문 (히어로, 대표 메뉴, 소개, 오시는 길, 푸터) |
| `style.css` | 스타일 (반응형 레이아웃, 카페 느낌의 갈색 톤) |

## 실행 방법

`index.html` 파일을 브라우저에서 열면 바로 확인할 수 있습니다.

## 참고

- 상호명, 주소, 전화번호, 메뉴 가격은 모두 예시 값입니다.
- AI 에이전트 수업 실습용으로 만들었습니다.
